# 🎨 Palette Cam

Palette Cam is a camera-based color tool that helps you explore color palettes and outfit combinations.

## 🚧 Status

Currently in development.

## 💡 What I'm Building

The goal is to create a web app that:

- Uses the camera to identify a color
- Generates complementary color palettes
- Suggests colors that would work well together in an outfit for any occasion
- Provides an interactive way to explore different color combinations

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- HTML/CSS
